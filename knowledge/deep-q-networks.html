Deep Q-Networks (DQN) and Q-Learning

techniquefreshness: stablesources not yet verified

Q-learning learns the value of taking each action in each state; DQN uses a neural network to do this from raw inputs such as game pixels.

Short answer: Q-learning estimates expected return for each (state, action) and acts greedily on it. DQN adds a neural network, experience replay and a target network to make this work on high-dimensional inputs with discrete actions.

What is it?

Q-learning keeps a score for every action in every situation: "if I'm here and do this, how good will things turn out?" DQN replaces the giant lookup table with a neural network, which let a single system learn to play many Atari games from the screen pixels.

Also known as: DQN, Q-learning, Q learning, deep Q network, experience replay, target network, value-based RL.

Technical definition

Q-learning (Watkins & Dayan, 1992) updates Q(s,a) toward r + γ max_a' Q(s',a'). DQN (Mnih et al., 2015) stabilises deep Q-learning with experience replay and a periodically updated target network; extensions include Double DQN, dueling networks, prioritised replay and Rainbow. It suits discrete action spaces; continuous control typically uses actor-critic methods.

Entity type: technique · Freshness class: stable.

When should I use it?

Use for discrete-action problems such as games and some operations tasks.

Prerequisites and related concepts

Understand these first: Markov Decision Processes, Reinforcement Learning.

Related concepts: Proximal Policy Optimization (PPO), World Models, Deep Learning.

Implementation patterns

  • Replay buffer with random minibatches.
  • Target network updated slowly.
  • ε-greedy exploration with decay.
  • Double DQN to reduce overestimation.

Technologies and frameworks

Commonly associated: Stable-Baselines3, Gymnasium / Atari, RLlib. Names are examples of what exists, not recommendations, and projects change quickly.

Practical guide

  1. Check actions are discrete.
  2. Use a vetted implementation.
  3. Tune replay size, target update rate, ε schedule.
  4. Evaluate across seeds.

Common failure modes

  • Overestimation bias.
  • Instability without replay/target networks.
  • Poor exploration in sparse-reward tasks.
  • Applying it to continuous actions without adaptation.

Troubleshooting

  • Q-values explode — Use Double DQN, gradient clipping, reward clipping/normalisation.
  • No learning in sparse rewards — Better exploration, reward shaping or curriculum.

Contrasted with

  • Proximal Policy Optimization (PPO) — PPO learns a policy directly and handles continuous actions; DQN learns action values for discrete actions.
