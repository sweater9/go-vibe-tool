Graph Neural Networks (GNNs)

conceptfreshness: stablesources not yet verified

GNNs learn from data shaped like graphs — molecules, social networks, road maps — by passing messages between connected nodes.

Short answer: A GNN updates each node's representation by aggregating messages from its neighbours over several rounds. It suits relational data (molecules, networks, recommendation); over-smoothing and scalability are known challenges.

What is it?

Some data is naturally a network: atoms joined by bonds, people connected by friendships. A graph neural network lets each node repeatedly "ask its neighbours" and update what it knows, so after a few rounds each node's summary reflects its surroundings.

Also known as: GNN, GCN, graph convolutional network, message passing, GraphSAGE, GAT, graph attention network, graph deep learning.

Technical definition

Message-passing framework (Gilmer et al., 2017): h_v^{k+1} = U(h_v^k, AGG({M(h_u^k, h_v^k, e_uv)})). Variants: GCN (Kipf & Welling, 2016), GraphSAGE, GAT (attention), and graph transformers. Tasks: node, edge and graph-level prediction. Challenges: over-smoothing with depth, over-squashing, scaling to large graphs (sampling), and expressiveness limits (Weisfeiler–Lehman). Applications include molecules and materials (AI in Drug Discovery, AI for Materials Discovery) and weather models such as GraphCast (AI Weather and Climate Forecasting Models).

Entity type: concept · Freshness class: stable.

When should I use it?

Use when relationships between entities carry the signal.

Prerequisites and related concepts

Understand these first: Neural Networks.

Related concepts: AI for Science, AI in Drug Discovery, AI for Materials Discovery, AI Weather and Climate Forecasting Models, GraphRAG (Knowledge-Graph Retrieval).

Implementation patterns

  • Node classification with neighbourhood sampling.
  • Graph-level prediction with readout pooling (molecular property prediction).
  • Edge prediction for recommendations/link prediction.
  • Equivariant GNNs for 3-D physical systems.

Technologies and frameworks

Commonly associated: PyTorch Geometric, DGL, Jraph, NetworkX. Names are examples of what exists, not recommendations, and projects change quickly.

Practical guide

  1. Define nodes, edges and features.
  2. Split train/test carefully for graphs.
  3. Start with GCN/GraphSAGE baselines.
  4. Add domain symmetries where relevant.

Common failure modes

  • Over-smoothing with many layers.
  • Memory blow-up on large graphs.
  • Leakage between train and test nodes in transductive setups.
  • Poorly defined graph construction.

Troubleshooting

  • Performance drops with depth — Use fewer layers, residual connections, or different aggregators.
  • Out of memory — Neighbourhood sampling or cluster-based mini-batching.

Contrasted with

  • GraphRAG (Knowledge-Graph Retrieval) — GraphRAG uses knowledge graphs to organise retrieval for LLMs; GNNs are learned models over graph-structured data.
  • Convolutional Neural Networks (CNNs) — CNNs assume a regular grid; GNNs handle irregular connectivity.
