Deep Learning

conceptfreshness: stablesources not yet verified

Deep learning is machine learning with neural networks that have many layers, learning useful features directly from raw data like pixels, audio and text.

Short answer: Deep learning = many-layer neural networks that learn their own features from raw data. Its success rests on data, compute and architectures like CNNs and transformers; it needs more data and compute than classical ML.

What is it?

Deep learning is the branch of machine learning that uses neural networks with many layers. Instead of an engineer hand-crafting features ("edges", "word counts"), the network learns them itself from raw pixels, sound or text. This is behind modern image recognition, speech and language models.

Also known as: DL, deep neural networks, DNN, deep nets, deep learning explained, deep learning vs machine learning.

Technical definition

Deep networks learn hierarchical representations; success on modern benchmarks has been enabled by large datasets, GPU/accelerator compute, better optimisation (Adam, normalisation layers, residual connections) and architectures suited to the data modality. LeCun, Bengio & Hinton (2015) give a canonical overview. Costs: data hunger, compute, limited interpretability and sensitivity to distribution shift.

Entity type: concept · Freshness class: stable.

When should I use it?

Use for images, audio, language and other unstructured data, or when pre-trained models can be adapted.

Prerequisites and related concepts

Understand these first: Neural Networks.

Related concepts: Backpropagation and Gradient Descent, Convolutional Neural Networks (CNNs), What is a Transformer? (Attention Explained), Transfer Learning, GPUs and AI Accelerators, What is Artificial Intelligence?.

Implementation patterns

  • Use pre-trained backbones and fine-tune.
  • Mixed-precision training on GPUs.
  • Residual connections and normalisation layers for depth.
  • Data augmentation for perception tasks.

Technologies and frameworks

Commonly associated: PyTorch, JAX, TensorFlow, CUDA. Names are examples of what exists, not recommendations, and projects change quickly.

Practical guide

  1. Establish a classical-ML baseline.
  2. Choose a pre-trained model for your modality.
  3. Fine-tune with a small learning rate.
  4. Evaluate on held-out data with realistic shifts.
  5. Plan serving cost (Model Serving and Inference Infrastructure).

Common failure modes

  • Training from scratch on tiny data.
  • Ignoring simpler baselines.
  • Irreproducible results from uncontrolled randomness.
  • Silent failure under distribution shift.

Troubleshooting

  • Model overfits — More data/augmentation, regularisation, smaller model or pre-trained start.
  • Training too slow — Use mixed precision, bigger batches, better data loading, or smaller models.

Contrasted with

  • What is Artificial Intelligence? — AI is the broad field; deep learning is one family of methods inside machine learning.
  • Supervised Learning — Learning paradigm; deep learning is a model family usable in several paradigms.
