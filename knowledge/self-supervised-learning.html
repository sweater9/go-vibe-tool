Self-Supervised Learning

techniquefreshness: stablesources not yet verified

Self-supervised learning creates its own training signal from raw data — predicting hidden words, masked patches or the next token — and is how most foundation models are pre-trained.

Short answer: The model learns by solving tasks made from the data itself (predict the next token, fill in a masked word or patch). No human labels are needed, which makes training on huge corpora feasible.

What is it?

Hide part of the data and ask the model to predict it: the next word in a sentence, a masked patch of an image. The data supplies its own answers, so you can learn from enormous unlabelled collections. This is how large language models are pre-trained.

Also known as: SSL, self supervised, pretext task, masked language modeling, masked language modelling, next token prediction pretraining, masked autoencoder.

Technical definition

Pretext objectives include autoregressive next-token prediction (GPT-style), masked language modelling (BERT), masked autoencoding (MAE for images), and contrastive objectives (Contrastive Learning and CLIP). The learned representations are then adapted by What is Fine-Tuning an AI Model? or used frozen. Quality depends on data scale, diversity and objective design.

Entity type: technique · Freshness class: stable.

When should I use it?

Relevant whenever you use or adapt foundation models; rarely something an application team trains from scratch.

Prerequisites and related concepts

Understand these first: Supervised Learning, Unsupervised Learning.

Related concepts: What is a Large Language Model (LLM)?, What is a Transformer? (Attention Explained), Contrastive Learning and CLIP, Transfer Learning, Scaling Laws, What is Fine-Tuning an AI Model?.

Implementation patterns

  • Pre-train on large unlabelled data, then fine-tune on small labelled data.
  • Use frozen self-supervised embeddings with a small classifier head.
  • Continue pre-training on domain text before task fine-tuning.

Technologies and frameworks

Commonly associated: BERT-style masking, GPT-style autoregression, MAE, SimCLR. Names are examples of what exists, not recommendations, and projects change quickly.

Practical guide

  1. Choose a pre-trained model where possible instead of pre-training from scratch.
  2. Match the pretext objective family to your modality.
  3. Evaluate on your downstream task.
  4. Check pre-training data licensing and bias.

Common failure modes

  • Pre-training data bias propagated downstream.
  • Pretext task mismatched to the downstream task.
  • Underestimating the compute and data needed.

Troubleshooting

  • Poor transfer to the target domain — Continue pre-training on domain data or fine-tune with more in-domain examples.
  • Representations ignore needed features — Try a different objective or augmentations.

Contrasted with

  • Unsupervised Learning — Unsupervised finds structure; self-supervised builds a prediction task from the data.
  • Supervised Learning — Supervised uses human labels.
