LLM Cost Optimization

techniquefreshness: volatilesources not yet verified

Reduce the spend of LLM applications by sending fewer tokens, using the right-sized model, caching, batching, routing and limiting retries — while measuring quality so savings do not erode it.

Short answer: Levers: fewer input tokens, shorter outputs, smaller or routed models, caching, batch APIs for non-urgent jobs, capped retries and reasoning effort, and self-hosting at steady scale. Measure cost per successful task, not per call.

What is it?

LLM bills grow with the amount of text processed and the size of the model used. Most savings come from not sending unnecessary text, not using a premium model where a cheap one suffices, and reusing work that has already been done.

Also known as: reduce LLM costs, token cost optimization, LLM pricing, cheaper LLM calls, model routing, FrugalGPT, batch API, cost per token.

Technical definition

Techniques: prompt compaction and retrieval of only relevant context, output length limits, structured outputs to avoid verbose prose, model cascades/routers (FrugalGPT, Chen et al., 2023), Prompt Caching, batch/offline endpoints where offered, response caching for repeated queries, Thinking Budgets and Reasoning Effort for reasoning models, retries with backoff and caps, distillation (Knowledge Distillation) and quantised self-hosting (Quantization of AI Models). Evaluate quality at each step (How to Evaluate AI Systems and Outputs). Prices and discounts vary by provider and change; always compute with current price lists.

Entity type: technique · Freshness class: volatile.

When should I use it?

Apply once usage is meaningful or costs are unpredictable.

Prerequisites and related concepts

Understand these first: What are Tokens in AI?, What is a Context Window?.

Related concepts: Prompt Caching, Thinking Budgets and Reasoning Effort, Knowledge Distillation, Quantization of AI Models, Model Serving and Inference Infrastructure, LLM Observability (Tracing, Logging and Monitoring), Small Language Models (SLMs).

Implementation patterns

  • Cost per successful task as the KPI.
  • Cascade: cheap model → escalate on low confidence.
  • Trim context via retrieval and summarisation.
  • Cache deterministic repeated queries.
  • Set per-user and per-request budgets.

Technologies and frameworks

Commonly associated: model routers/gateways, provider batch APIs, caching layers, vLLM. Names are examples of what exists, not recommendations, and projects change quickly.

Practical guide

  1. Instrument tokens and cost per feature.
  2. Find the top spenders.
  3. Apply cheapest fix first (trim prompts, cache).
  4. Test model downgrades on evals.
  5. Set alerts and budgets.

Common failure modes

  • Optimising cost without quality checks.
  • Retry storms multiplying spend.
  • Ignoring output and reasoning tokens.
  • Forecasting with average rather than tail usage.

Troubleshooting

  • Bills spike — Inspect traces for retries, long contexts and runaway agents; add budgets.
  • Quality drops after switching models — Evaluate on your set before rollout; route only safe cases.

Setting it well balances accuracy, latency and cost.ConceptKnowledge DistillationDistillation trains a smaller student model to imitate a larger teacher, capturing much of its behaviour at lower cost.ConceptQuantization of AI ModelsQuantisation stores and computes a model's numbers at lower precision — for example 8-bit or 4-bit — to cut memory and often speed up inference, at some quality cost.ConceptModel Serving and Inference InfrastructureServing turns a trained model into a reliable service: loading it on suitable hardware, batching requests, managing memory, scaling, and meeting latency and cost targets.ConceptLLM Observability (Tracing, Logging and Monitoring)LLM observability records prompts, retrieved context, tool calls, outputs, latency, cost and feedback so teams can debug, evaluate and improve AI applications — while protecting sensitive data in those logs.ConceptSmall Language Models (SLMs)Small language models are compact LLMs — typically up to a few billion parameters — that run cheaply, often on laptops or phones, and can match larger models on narrow tasks.ConceptWhat are Tokens in AI?Tokens are the chunks of text — whole words, word pieces or punctuation — that language models read and write. Limits and pricing are usually measured in them.ConceptWhat is a Context Window?The context window is the maximum amount of text, measured in tokens, that a model can consider in a single request.
