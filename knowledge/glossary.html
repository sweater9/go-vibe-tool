AI Glossary A–Z

Clear definitions of 143 AI terms, with a link to the full explanation where one exists.

ABCDEFGHIJKLMNOPQRSTVWZ

A

A2A (Agent2Agent)
An open protocol for communication between independent AI agents: discovering capabilities, delegating tasks and returning results. It complements MCP, which connects agents to tools. Details are version-dependent.
Learn more: A2A (Agent2Agent) Protocol · A2A vs MCP
See also: MCP (Model Context Protocol)
Agent (AI agent)
A system in which a model pursues a goal by repeatedly choosing actions, calling tools and reading the results until it finishes or hits a limit.
Learn more: What are AI Agents? · AI Agent vs Chatbot vs Assistant: What's the Difference?
See also: Tool · Agentic workflow
Agentic workflow
A designed process that combines model calls, tools, checks and sometimes humans along a path the developer defines, as opposed to a model freely choosing every step.
Learn more: Agentic Workflows: Patterns for Reliable AI Automation
See also: Agent
AI (Artificial Intelligence)
The broad field of building software that performs tasks normally associated with human judgement, such as perception, language and decision-making.
Learn more: What is Artificial Intelligence?
See also: Machine learning · Deep learning
Alignment
Work to make AI systems behave in line with human intentions and values, including being helpful, honest and safe. Training steps such as instruction tuning and preference tuning contribute to it.
Learn more: What is a Large Language Model (LLM)?
See also: Instruction tuning · RLHF
API key
A secret string a program sends to an API to identify itself. Anyone who has the key can call the API as that program, so it belongs on a server, not in a browser.
Learn more: API Keys · Environment Variables
Approximate nearest neighbour (ANN)
A family of search methods that quickly find vectors that are very likely, though not guaranteed, to be the closest to a query. Used by vector databases to stay fast at scale.
Learn more: What is a Vector Database?
See also: Vector database
Attention
The mechanism in a transformer that lets each token weigh how relevant every other token is when building its representation.
Learn more: What is a Transformer? (Attention Explained)
See also: Transformer
Authorization code flow
The usual OAuth 2.0 flow for user login: the browser gets a short-lived code, and the server exchanges that code for tokens. Public clients add PKCE so a stolen code is not enough.
Learn more: OAuth 2.0 · OpenID Connect

B

Backpropagation
The algorithm that computes how each parameter contributed to the loss, so gradient descent can update it.
Learn more: Backpropagation and Gradient Descent
See also: Neural network
Benchmark
A standard test used to compare models on a defined task. Useful for rough comparison, but not a substitute for testing on your own use case.
Learn more: How to Evaluate AI Systems and Outputs
See also: Evals
Best-of-N sampling
Generating several candidate answers and returning the one a scorer — tests, a verifier or a reward model — rates highest.
Learn more: Best-of-N Sampling
See also: Self-consistency

C

C# (C sharp)
A statically typed language on .NET, commonly used for APIs, workers and Azure services in Microsoft-centred stacks.
Learn more: C#
C2PA (Content Credentials)
An open standard for cryptographically signed provenance metadata describing how media was made and edited, including AI generation.
Learn more: C2PA and Content Provenance (Content Credentials)
See also: Diffusion model
Chain of thought
A prompting technique in which the model is encouraged to work through intermediate reasoning steps before giving its answer. Its usefulness varies by model and task.
Learn more: Prompt Engineering: How to Write Better AI Prompts
See also: Prompt
Chatbot
Software that converses with users. Modern chatbots are usually powered by LLMs; the word says little about whether the system can take actions.
Learn more: AI Agent vs Chatbot vs Assistant: What's the Difference?
See also: Agent
Chunking
Splitting documents into smaller passages so each can be embedded and retrieved on its own, as in RAG.
Learn more: Chunking: How to Split Documents for RAG · What is RAG (Retrieval-Augmented Generation)?
See also: Embedding · RAG
Constitutional AI
A training approach in which a model critiques and revises its outputs against written principles, with AI-generated preference labels (RLAIF) used for further training.
Learn more: Constitutional AI and RLAIF (AI Feedback)
See also: RLHF
Constrained decoding (guided generation)
Restricting a model's next-token choices at each step so output must follow a schema, regex or grammar. It guarantees well-formed output, not correct content.
Learn more: Constrained Decoding (Guided Generation) · Structured Outputs from LLMs
See also: Structured output
Container
A process isolated with its own filesystem view, built from an image and run by a container runtime. It shares the host kernel, unlike a virtual machine.
Learn more: Containers · Docker
Context engineering
Curating everything a model sees each turn — instructions, retrieved facts, memory, tool definitions and results — so agents stay reliable.
Learn more: Context Engineering · What is a Context Window?
See also: Context window
Context window (context length)
The maximum amount of text, measured in tokens, a model can consider in one request, covering instructions, conversation, documents and the reply.
Learn more: What is a Context Window? · What are Tokens in AI?
See also: Token
Contrastive learning
Training that pulls matching pairs (such as an image and its caption) together in embedding space and pushes non-matching pairs apart. CLIP is a well-known example.
Learn more: Contrastive Learning and CLIP
See also: Embedding
CORS (Cross-Origin Resource Sharing)
A browser check that asks a server whether a page from another origin may read the response. It is not authentication, and non-browser clients ignore it.
Learn more: CORS
Cosine similarity
A measure of how closely two vectors point in the same direction. It is widely used to compare embeddings: values near 1 mean very similar, near 0 mean unrelated.
Learn more: What are Embeddings in AI?
See also: Embedding · Vector

D

Deep learning
Machine learning that uses neural networks with many layers. It underlies most modern vision, speech and language models.
Learn more: What is Artificial Intelligence?
See also: Machine learning · Neural network
Diffusion model
A generative model, common in image generation, that starts from random noise and refines it step by step into content matching a prompt.
Learn more: What is Generative AI?
See also: Generative AI
Direct Preference Optimization (DPO) (DPO)
A preference-optimization method that tunes a model directly on chosen-versus-rejected response pairs relative to a reference model, without a separate reward model or RL loop. It is an alignment technique, not ordinary reinforcement learning.
Learn more: Direct Preference Optimization (DPO) · Preference Optimization (Aligning Models from Human or AI Preferences)
See also: RLHF
Distillation (knowledge distillation)
Training a smaller student model to imitate a larger teacher model's outputs, yielding a cheaper model for narrower tasks.
Learn more: Knowledge Distillation
See also: Quantisation

E

Embedding
A list of numbers (a vector) that represents the meaning of content so that similar items are close together. Basis of semantic search and RAG.
Learn more: What are Embeddings in AI? · What is a Vector Database?
See also: Vector · Semantic search
Embodied AI
AI that perceives and acts in the physical or simulated world through a body such as a robot arm, drone or vehicle.
Learn more: Embodied AI
See also: VLA (vision-language-action model)
Entra ID (Microsoft Entra ID, Azure AD)
Microsoft's cloud identity service, formerly Azure Active Directory. It signs users in and issues tokens for Microsoft 365, Azure and registered apps.
Learn more: Microsoft Entra ID · OAuth 2.0
EU AI Act
The European Union's risk-based regulation of AI systems, Regulation (EU) 2024/1689. Application dates are phased; verify the current timetable.
Learn more: EU AI Act
See also: Guardrails
Evals (evaluations)
Structured tests that measure how well an AI system performs on tasks you care about, using test cases, graders and tracked scores.
Learn more: How to Evaluate AI Systems and Outputs
See also: Benchmark
Express
A small Node.js library for HTTP routes and middleware. It does not include a database or a front end.
Learn more: Express · Node.js

F

Few-shot prompting
Including a small number of example inputs and outputs in the prompt to show the model the pattern you want. Zero-shot means giving no examples.
Learn more: Prompt Engineering: How to Write Better AI Prompts
See also: Zero-shot prompting · Prompt
Fine-tuning
Further training a pre-trained model on your own examples so it adopts a consistent behaviour, format or skill.
Learn more: What is Fine-Tuning an AI Model? · RAG vs Fine-Tuning: Which Should You Use?
See also: LoRA · RAG
FlashAttention
An exact attention algorithm that tiles computation to cut memory traffic, speeding up transformers and enabling longer sequences without approximating the result.
Learn more: FlashAttention
See also: Attention
Foundation model
A large model trained on broad data that can be adapted to many tasks. Large language models are the best-known example.
Learn more: What is a Large Language Model (LLM)? · What is Generative AI?
See also: LLM
Function calling (tool calling)
A model-API feature in which the model returns a structured request to run a named function with arguments. Your code runs it and returns the result.
Learn more: Function Calling (Tool Calling) Explained · Function Calling vs MCP
See also: Tool · MCP

G

Generative AI
AI that produces new content such as text, images, audio, video or code.
Learn more: What is Generative AI?
See also: LLM · Diffusion model
GGUF
A model file format used by llama.cpp, supporting many quantisation levels and bundling metadata for local inference.
Learn more: llama.cpp · Quantization of AI Models
See also: Quantisation
Git
A distributed version-control system that records snapshots of a project so you can branch, merge and recover history.
Learn more: Git · GitHub
Graph neural network (GNN)
A neural network that learns on graph-structured data by passing messages between connected nodes, used for molecules, networks and some weather models.
Learn more: Graph Neural Networks (GNNs)
See also: Neural network
GraphQL
An API style in which the client names the fields it wants and the server resolves them against a schema. Not the same thing as Microsoft Graph.
Learn more: GraphQL · REST versus GraphQL
GraphRAG
Retrieval that builds a graph of entities and relationships (often with community summaries) so questions needing connections or corpus-wide synthesis can be answered.
Learn more: GraphRAG (Knowledge-Graph Retrieval)
See also: RAG (Retrieval-Augmented Generation)
Grounding
Tying a model's answer to supplied source material or tool results so claims can be traced and checked.
Learn more: How to Reduce AI Hallucinations · What is RAG (Retrieval-Augmented Generation)?
See also: RAG · Hallucination
GRPO (Group Relative Policy Optimization)
A PPO-style reinforcement-learning method that normalises rewards within a group of sampled outputs per prompt, avoiding a separate value model. Used for training on tasks with verifiable rewards.
Learn more: Reinforcement Learning for Reasoning (RLVR and GRPO)
See also: PPO (Proximal Policy Optimization)
Guardrails
Checks and limits around an AI system, such as input filters, output validation, permission limits and human approvals, that reduce harmful or unwanted behaviour.
Learn more: AI Privacy and Security: What to Know Before You Paste Data · What is Prompt Injection?
See also: Prompt injection

H

Hallucination
Fluent, confident model output that is false, unsupported by the sources, or invented, such as fake citations or facts.
Learn more: AI Hallucinations: Why Models Make Things Up · How to Reduce AI Hallucinations
See also: Grounding
Hugging Face (HF)
A hub and set of libraries for publishing and loading machine-learning models and datasets, including the transformers library.
Learn more: Hugging Face for Builders
Human in the loop
A design in which a person reviews or approves AI output or actions at defined points, especially before high-impact or irreversible steps.
Learn more: Agentic Workflows: Patterns for Reliable AI Automation · What are AI Agents?
See also: Agentic workflow
Hybrid search
Combining keyword search with vector similarity (often plus metadata filters), so exact terms and meaning are both covered.
Learn more: Vector Database vs Traditional Database · What is RAG (Retrieval-Augmented Generation)?
See also: Semantic search

I

Inference
Running a trained model to produce output for new input, as opposed to training it.
Learn more: What is a Large Language Model (LLM)? · What is Local AI? Running Models on Your Own Device

Instruction tuning
Additional training that teaches a pre-trained model to follow instructions and respond helpfully, turning a text predictor into an assistant.

J

Jailbreak
An attempt to get a model to break its safety rules through crafted input. Related to, but distinct from, prompt injection.
Learn more: What is Prompt Injection?
See also: Prompt injection
JSON Web Token (JWT)
A signed token whose payload is JSON. The payload is readable by anyone; trust comes only from checking the signature, issuer, audience and expiry.
Learn more: JSON Web Tokens · OAuth 2.0

K

Knowledge cut-off
The point after which a model's training data contains no information. Later events are unknown to it unless supplied via the prompt, search or tools.
Learn more: What is a Large Language Model (LLM)?
See also: LLM
KV cache
Stored attention keys and values for earlier tokens, reused during generation to avoid recomputation. It speeds decoding but grows with context length and batch size.

L

LangChain
A framework for composing model calls, tools and retrieval in Python or JavaScript. It is optional glue, not a model.

llama.cpp

LlamaIndex (Llama Index)
A framework focused on loading documents, indexing them and retrieving context for a language model.
Learn more: LlamaIndex for Retrieval · RAG Frameworks
LLM (Large Language Model)
A very large neural network trained on text to predict the next token, enabling writing, summarising, translation, question answering and code generation.

A protocol for granting an application limited access to an API without sharing the user's password. OpenID Connect adds sign-in identity on top.

Models whose trained parameters are published for download and local use, subject to the licence. Not always the same as fully open source.

An identity layer on OAuth 2.0. The ID token says who signed in. The access token is what you send to an API.

A library that maps database rows to objects in a programming language. Prisma is one TypeScript example. The SQL still runs.

Parameters (weights)
The numbers inside a model that are adjusted during training and determine its behaviour. Model size is often quoted as a parameter count.

Perplexity
A language-modelling metric reflecting how well a model predicts text; lower means less "surprised". It is not a measure of usefulness or truth.

Power Platform
Microsoft's low-code family: Power Apps, Power Automate, Power BI and Dataverse, used for tenant workflows beside Microsoft 365.

A setting that controls randomness when a model picks the next token. Lower values give more predictable output; higher values give more varied output.

The unit of text a model reads and writes: a word, part of a word, or punctuation. Limits and prices are commonly measured in tokens.

Tokenizer
The component that splits text into tokens and maps them to numbers. Different model families use different tokenizers.

Training

Vision Transformer (ViT)
A transformer that splits an image into patches treated as tokens, matching or beating CNNs at scale.
Learn more: Vision Transformers (ViT) · CNN vs Vision Transformer
See also: Transformer
Vision-language model (VLM)
A model that takes images (and often video) with text and produces text: descriptions, answers about charts and screenshots, visual reasoning.
Learn more: Vision-Language Models (VLMs)
See also: Multimodal
VLA (vision-language-action model)
A model that maps camera images and a language instruction to robot actions, extending vision-language models to control.
Learn more: Vision-Language-Action (VLA) Models
See also: Embodied AI
vLLM
An open-source LLM serving engine known for paged KV-cache memory and continuous batching.
Learn more: vLLM · Local and Self-Hosted LLM Runtimes Compared
See also: KV cache

Webhook
An HTTP callback: another system POSTs to your URL when an event happens. Verify the signature and treat retries as normal.
Learn more: Webhooks
World model
A learned model of how an environment evolves in response to actions, used for planning, imagination-based training or generated simulation.
Learn more: World Models
See also: Embodied AI

Z

Zero-shot prompting
Asking a model to perform a task with instructions only and no examples.
