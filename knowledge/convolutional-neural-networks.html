Convolutional Neural Networks (CNNs)

conceptfreshness: stablesources not yet verified

CNNs process grid-like data such as images by sliding small learned filters across it, capturing local patterns with far fewer parameters than fully connected nets.

Short answer: A CNN uses convolutions with shared filters, pooling and depth to build up from edges to objects. It exploits locality and translation structure in images; vision transformers now compete with and sometimes replace it.

What is it?

A CNN looks at an image through small windows, learning filters that detect edges, textures and then shapes. Because the same filter slides across the whole image, it needs far fewer weights and recognises a pattern wherever it appears.

Also known as: CNN, ConvNet, convolution, ResNet, AlexNet, image classification network, convolutional network, pooling layer.

Technical definition

Convolutional layers compute local, weight-shared linear filters followed by non-linearities, often with pooling or strided convolutions and normalisation; residual connections (ResNet, He et al., 2015) enable very deep networks. Inductive biases (locality, translation equivariance) make CNNs data-efficient on images. They are also used for audio spectrograms and 1-D signals. Competing/complementary designs include Vision Transformers (ViT) and hybrids.

Entity type: concept · Freshness class: stable.

When should I use it?

Strong default for image tasks, especially with limited data or compute.

Prerequisites and related concepts

Understand these first: Neural Networks.

Related concepts: Vision Transformers (ViT), CNN vs Vision Transformer, Deep Learning, Transfer Learning, What is Multimodal AI?.

Implementation patterns

  • Pre-trained backbone + task head.
  • Data augmentation (crop, flip, colour jitter).
  • Residual connections.
  • Mixed precision on GPUs.

Technologies and frameworks

Commonly associated: PyTorch / torchvision, ResNet, EfficientNet, ConvNeXt. Names are examples of what exists, not recommendations, and projects change quickly.

Practical guide

  1. Start from a pre-trained backbone.
  2. Match preprocessing to it.
  3. Fine-tune with a small learning rate.
  4. Test on realistic shifted data.

Common failure modes

  • Overfitting small image sets.
  • Sensitivity to distribution shift (lighting, camera).
  • Shortcut learning on background cues.
  • Inappropriate input resizing.

Troubleshooting

  • Great on validation, poor in the field — Collect field-like data; augment; test on shifted sets.
  • Model focuses on background — Rebalance data; use saliency checks.

Contrasted with

  • Vision Transformers (ViT) — ViT splits images into patches and uses attention; CNNs use local filters with built-in spatial bias.
  • Recurrent Neural Networks and LSTMs — RNNs process sequences step by step; CNNs process grids/windows in parallel.
