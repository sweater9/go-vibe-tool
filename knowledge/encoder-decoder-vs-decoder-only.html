Encoder-Only, Decoder-Only and Encoder-Decoder Models

conceptfreshness: stablesources not yet verified

Transformer models come in three layouts: encoders for understanding, decoders for generating, and encoder-decoders for transforming one sequence into another.

Short answer: Encoder-only (BERT-style): understanding, classification, embeddings. Decoder-only (GPT-style): generation and the dominant chat LLM layout. Encoder-decoder (T5-style): sequence-to-sequence tasks like translation.

What is it?

Transformers are built in three layouts. Encoders read a whole text and produce a rich understanding of it (great for search and classification). Decoders write text one token at a time (the chat models). Encoder-decoders read one text and write another (translation, summarisation).

Also known as: encoder vs decoder, BERT vs GPT, decoder-only, encoder-only, seq2seq transformer, T5, causal language model, bidirectional model.

Decoder-only models dominate current general-purpose LLMs partly for scaling simplicity and in-context learning; the other layouts remain strong for specific tasks.

Entity type: concept · Freshness class: stable.

When should I use it?

Pick the layout matching the task; default to decoder-only for open-ended generation.

Prerequisites and related concepts

Understand these first: What is a Transformer? (Attention Explained).

Implementation patterns

  • Encoder for classification/embedding; decoder for generation.
  • Encoder-decoder for translation/summarisation where input and output are distinct sequences.

Technologies and frameworks

Commonly associated: BERT, T5, GPT-style decoders, Hugging Face Transformers. Names are examples of what exists, not recommendations, and projects change quickly.

Practical guide

  1. Classify task: understand, generate or transform.
  2. Pick the layout.
  3. Choose a pre-trained model of that type.
  4. Compare cost and quality.

Common failure modes

  • Using a generative LLM where a small encoder would be cheaper and sufficient.
  • Expecting BERT-style encoders to generate fluent text.

Troubleshooting

  • Classification is slow/expensive — Try a fine-tuned small encoder.
