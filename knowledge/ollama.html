Ollama

runtimefreshness: volatilesources not yet verified

Ollama is a tool that downloads, manages and runs open models locally with a simple command line and a local HTTP API.

Short answer: Ollama makes local models easy to pull and run (ollama run <model>) and exposes a local API (default port 11434). It wraps inference engines and a model library; check current docs for supported models, formats and settings.

What is it?

Ollama is the "app store plus launcher" for local AI. One command downloads a model and starts a chat; other programs can talk to it through a local web address on your own machine.

Also known as: ollama run, ollama serve, ollama modelfile, run LLM locally easily, ollama API, ollama localhost 11434, ollama models.

Technical definition

Ollama packages models with configuration (Modelfile), manages downloads and storage, and serves a REST API on localhost (default 11434) with an optional OpenAI-compatible endpoint. Historically built on llama.cpp-family engines; engine details have evolved, so verify. Structured-output and tool-calling support depend on version and model.

When should I use it?

Good default for local experimentation and development.

Implementation patterns

  • Local dev environment with an OpenAI-compatible client pointed at localhost.
  • Modelfile to set system prompt and parameters.
  • Keep the API bound to localhost.

Technologies and frameworks

Commonly associated: Ollama CLI and API, Modelfile, GGUF models. Names are examples of what exists, not recommendations, and projects change quickly.

Practical guide

  1. Install from the official site.
  2. Pull a small model first.
  3. Test via CLI and API.
  4. Set parameters via Modelfile.
  5. Keep it local or secure it.

Common failure modes

  • Exposing the API publicly without authentication.
  • Models too large for available memory.
  • Assuming parity with hosted model features.
  • Trusting unvetted community models.

Troubleshooting

  • Connection refused — Check the service is running and the port/host settings.
  • Slow responses — Pick a smaller or more quantised model; confirm GPU use.

Contrasted with

  • llama.cpp — llama.cpp is the lower-level engine; Ollama adds management and APIs.
  • vLLM — vLLM targets multi-user GPU serving; Ollama targets personal/local use.
