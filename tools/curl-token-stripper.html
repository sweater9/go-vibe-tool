GOOD TO KNOW

Clear expectations before you use it.

Is this a full shell or cURL parser?

No. It is a local sharing-safety helper that targets common credential patterns. Review the sanitized request before publishing it.

Does redaction prove the request contains no secrets?

No. Unusual credentials or formats may not match the supported patterns, so a manual review is still important.
