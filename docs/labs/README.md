# GoVibeTool Labs review screenshots

Real Chromium full-page screenshots of the local checkout at 1280x900 (desktop) and 390x844 (touch mobile).
Files: `hub-`, `workflow-`, `api-playground-`, `ai-`, `cyber-`, `science-`, `finance-` + `desktop.png` / `mobile.png`.

Each lab is captured after one real interaction (workflow template run, neural network trained 200 epochs,
one-bit hash change, projectile launched, API request sent) so results are visible.

Capture notes: smooth scrolling is disabled, the page is scrolled to the top, and the sticky header and the
off-screen "skip to content" link are neutralised for the full-page capture only. Without that, full-page
captures of long pages draw the sticky header mid-page. The site itself is unchanged.
No horizontal overflow and no console errors were observed on any of the 14 pages.
